# Privacy and Public Repositories

CV Execute is a public framework.

A real candidate evidence bank does **not** need to be public.

## Recommended separation

### Public
- CV Execute framework
- generic templates
- documentation
- fictional / anonymized examples

### Private candidate workspace
- real career history
- contact details
- application notes
- compensation preferences
- private employer research
- personal constraints
- internal evidence boundaries

### Never store as ordinary CV context
- passwords
- API keys
- bank credentials
- security answers
- identity-document numbers
- secrets that would create serious harm if exposed

## Public export rule

> **Public export is a transformation, not a copy.**

Before publishing a personal project/career artifact:
- remove direct contact details when unnecessary
- remove internal strategy notes
- remove private third-party information
- review dataset/content licenses
- remove credentials/secrets
- verify that every remaining claim is intentional and safe to publish

A private Git repository is not publicly visible, but it is still cloud storage and should be treated accordingly.
