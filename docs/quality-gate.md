# Quality Gate

Before submission, check the CV in five passes.

## 1. Claim audit

For every strong claim:
- What evidence supports this?
- Is it direct or adjacent?
- Did wording become stronger than the evidence?

Remove or weaken unsupported claims.

## 2. 10-second scan

Can a reader quickly understand:
- the target role
- why the candidate is relevant
- strongest current evidence
- major differentiators

If not, simplify.

## 3. Vacancy coverage

Do the most important employer criteria appear naturally?

Do not chase every keyword.

## 4. Readability

Check:
- font size
- spacing
- hierarchy
- repetition
- paragraph density
- bullet length
- visual noise

## 5. ATS / text extraction

For PDFs:
- text should remain selectable
- reading order should be logical
- headings and employer names should extract cleanly
- critical information should not depend on icons or graphics

A useful expected order:

> Name → target → contact → profile → capabilities → experience → technical/domain → education
