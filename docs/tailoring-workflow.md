# Tailoring Workflow

## 1. Parse the vacancy

Extract:
- role identity
- hard requirements
- repeated terminology
- tools / platforms
- support or operational mechanics
- performance language
- behavioural expectations
- domain-specific advantages

## 2. Build the evidence matrix

Map every important requirement to real candidate evidence.

Do not begin rewriting the CV before this step.

## 3. Form the hiring thesis

Write one sentence:

> If this employer needs ________, the candidate's strongest proof is ________.

This gives the CV a coherent direction.

## 4. Tailor selectively

A strong master CV normally needs targeted changes, not a complete rewrite.

Potential changes:
- headline
- profile
- capability order
- terminology
- bullet emphasis
- project selection
- technical/tool line
- which older evidence is surfaced

## 5. Verify

Check:
- unsupported claims
- exact employer terminology
- repeated claims
- relevance
- readability
- extraction order if exported to PDF

## 6. Preserve the evidence bank

Do not rewrite career history differently for every vacancy.

Update the evidence bank only when new facts are learned or corrected.
