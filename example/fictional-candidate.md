# Fictional Candidate Example

This example is intentionally fictional.

## Candidate

**Alex Morgan**

Target:
Technical Customer Support

## Evidence

### Field Service Technician | 2022–2025

Verified:
- diagnosed equipment faults at customer sites
- documented service visits
- explained repairs to customers
- escalated electrical issues to specialist technicians
- coordinated replacement parts

Supports:
- troubleshooting
- customer communication
- documentation
- issue ownership
- escalation

Does not establish:
- SaaS support experience
- Zendesk experience
- API troubleshooting

### Personal Web Project | 2025

Verified:
- built a small web application
- used browser developer tools while debugging
- worked with JSON from a public API

Supports:
- basic web troubleshooting
- JSON familiarity
- debugging
- technical learning

Does not establish:
- production software engineering tenure

## Example vacancy requirement

> "Experience troubleshooting customer issues in a SaaS environment."

Evidence state:
**ADJACENT**

Strong truthful CV wording:

> Customer-facing troubleshooting experience across field service, combined with hands-on web debugging and JSON/API project work.

Poor / unsupported wording:

> Three years of SaaS technical support experience.
